What to know about this release.

Is Matraca free?

Matraca is available under the MIT license, and the app is free to download. Local speech recognition does not require a paid API. If you enable text review through an external AI service, that provider may charge for usage.

Does it work on Windows and Mac?

A public installer is available for Windows x64. The macOS Apple Silicon package is being prepared and is not yet available on the GitHub releases page. Follow releases for availability and installation instructions. No Linux release has been announced.

Do I need an internet connection to dictate?

You need internet access to download the app and the speech recognition model. After that, local transcription can work offline. Remote AI review and balance checks require a connection when used.

Why might Windows show a warning?

This version of the installer is not yet code-signed. Check the file source, release notes and published SHA-256 on the official release page before deciding to install it. This page does not ask you to disable Windows protection.

Can it type into any app?

It is designed to insert text into editors, browsers, chats and terminals. Compatibility depends on the field and window permissions. If insertion fails, you can copy the message from history, when enabled.

How are AI review API keys stored?

In the current version, keys entered in the interface are stored in the local configuration file without encryption. You can also configure them through environment variables. No API key is needed for local dictation alone. See the review documentation.
